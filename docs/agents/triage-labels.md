# Triage Labels

Map each canonical triage role to its label in this repository's tracker.

| Canonical role    | Tracker label     | Meaning                                           |
| ----------------- | ----------------- | ------------------------------------------------- |
| `needs-triage`    | `needs-triage`    | Maintainer needs to evaluate the issue            |
| `needs-info`      | `needs-info`      | Waiting for more information from the reporter    |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an autonomous agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation                     |
| `wontfix`         | `wontfix`         | Will not be implemented                           |

When a skill names a triage role, use the tracker label from this table.
To change the vocabulary, edit the Tracker label column.
