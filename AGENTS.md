# AGENTS.md

OPDS catalog generator for local ebooks. It watches `/books`, extracts metadata and covers from epub/fb2/mobi/pdf/djvu/cbz/txt, and writes OPDS 1.2 feeds plus a browser viewer. Bun + TypeScript, nginx in front, everything runs in Docker. Synchronization (scans, scheduling, reconciliation, freshness, retry, shutdown) is the released `@seigiard/sync-engine` package (ADR 0004); OPDS keeps extraction, rendering, source policy and publication as Effect 4 handlers (ADR 0003).

`AGENTS.md` is the single source of truth for project context (`CLAUDE.md` is a symlink to it). Update it in the same change when you alter architecture, dependencies, commands, gotchas, or project structure. Deep topics live in `docs/agents/`; update the matching file there too.

`/data` mirrors `/books`. A book becomes a folder with `entry.xml`, `cover.jpg`, `thumb.jpg`, and a `file` symlink. A folder gets `feed.xml` and `_entry.xml` (consumed by its parent). The browser shell in `static/index.html` fetches and renders each folder feed; it is not generated in `/data`. `_app` and `_catalog` are reserved top-level folder names.

Markup and CSS changes do not need a folder processing-version bump. Bump the folder version when feed or entry links, or `_entry.xml`, change.

## Always-on rules

- `static/` and `test/golden/*` are generated. Change their sources, run `bun run build:ui` / `bun run render:golden`, and commit the output.
- Modules in a browser bundle stay free of node and Bun: no `node:` or `bun` imports, no `Bun` globals. `render:pure` builds every browser bundle and fails when a builtin reaches one, or when a bundled module falls outside the browser override in `.oxlintrc.json`; add such a module to that override's `files`.
